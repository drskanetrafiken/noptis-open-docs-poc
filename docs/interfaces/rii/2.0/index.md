# RII 2.0 – demonstrationssida

> **Ej officiell specifikation.** Innehållet visar endast struktur och redigeringsmöjligheter.

## Syfte

Här kan en arbetsgrupp testa rubriker, tabeller, länkar till XML-scheman och ändringsförslag.

## Testtabell

| Kontrollpunkt | Testfråga |
| --- | --- |
| Terminologi | Kan en bidragsgivare föreslå ett tydligare begrepp? |
| Versionshantering | Kan en publicerad version refereras utan att ändras? |
| XML-scheman | Kan granskare se ändringar i XSD och text i samma PR? |
| Exempel | Kan exempel kopplas till rätt specifikationsversion? |

## Fortsättning

- XML-scheman finns vid behov i repots `schemas/rii/2.0/` och granskas på GitHub.
- Exempel finns vid behov i repots `examples/rii/2.0/` och granskas på GitHub.

För riktiga XML-filer behöver VitePress-sidor länka till filernas publika GitHub-URL:er eller kopiera dem till en statisk publiceringsmapp. Prototypen automatiserar **inte** detta.
