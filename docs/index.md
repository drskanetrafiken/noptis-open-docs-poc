> **Endast ett test.** Denna webbplats innehåller inga officiella NOPTIS-specifikationer.

Syftet är att prova hur öppna specifikationer kan hanteras på GitHub med gemensam granskning, ändringshistorik och publicerade versioner.

## Prova flödet

- [RII – teststruktur](./interfaces/rii/index.md)
- Läs och diskutera ändringsförslag i GitHub Issues.
- Föreslå ändringar direkt i Markdown med Pull Requests.

**Princip:** Markdown och eventuella XSD-filer ska vara förvaltade källfiler. GitHub och den genererade webbplatsen visar samma innehåll.
