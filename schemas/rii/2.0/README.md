# RII 2.0 – XSD (plats för framtida test)

Inga officiella XML-scheman får läggas här utan klarlagda publiceringsrättigheter.

Vid en riktig import: bevara filnamn, `xs:include`/`xs:import`, namespace och inbördes sökvägar. Lägg till validering av XML-exempel i CI först när ett verkligt schema finns på plats.
